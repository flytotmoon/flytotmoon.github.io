# 这里是flytotmoon的博客

## 基于anzhiyu主题

![博客页面预览](https://xsxtk.oss-cn-beijing.aliyuncs.com/img/20260524201225098.png)

anzhiyu是一个基于butterfly主题的一个非常优秀的 **主题** 。同时可自定义的地方也非常多。

此主题也基于 HEXO 。作为一个广为人知的静态框架，以安全、小巧 `ps:主要是不用托管服务器，部署到github上就行了` 闻名。

{% link  anzhiyu主题安装,anzhiyu主题,https://docs.anheyu.com/ %}

本人写博客的方式是利用 typora + hexohub 实现。

typora 是一个强大的 markdown 编辑器， hexohub 是一个后台托管软件，日常用起来非常方便。

# 写在最后的话

总而言之，这是我 **分享生活** 的地方。随着信息时代的日新月异，这种个人博客越来越少，大部分人都舍弃了个人博客，开始转向第三方软件，例如知乎、微博等。

第三方软件固然方便，可是也失去了很多自定义的乐趣，以及严厉的审核让很多东西发不出来。

所以我选择了利用 hexo 搭建一个个人博客。固然缺少了很多流量， **可别有一番乐趣** ，不是么？

再见！
